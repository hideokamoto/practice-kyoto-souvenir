## 2. 追加ソースの詳細

### 2.1 京都府「観光施設一覧」
- URL: https://data.bodik.jp/dataset/260002_kankou_shisetsu （CSV: `260002kankoushisetsu.csv`、更新 2022-04-18）
- 概要文: 「京都府観光連盟公式サイト『京都府観光ガイド』に掲載されている観光スポット一覧です。」推奨データセット（政府の自治体標準オープンデータセット）形式。
- 列: 名称 / 名称_カナ / 住所 / 緯度 / 経度 / 利用可能日時特記事項 / 料金（詳細） / 説明 / アクセス方法 / 駐車場情報 / バリアフリー情報 / 連絡先 / URL など 32 列。画像・英語列は空。
- 京都市分 778 行（左京 133、右京 123、東山 118、中京 104、上京 72、下京 65 …）。説明文あり 776、座標あり 766。
- 用途: 地図問題（「この地点にあるのは？」）、距離問題（「○○から最も近いのは？」は端末内で haversine 計算可）、アクセス文からの「最寄りバス停」問題。

### 2.2 Wikidata
- 確認方法: `query.wikidata.org` に SPARQL。京都市（Q34600）内に位置し、寺院・神社・城のクラスに属し座標を持つ項目。
- 件数: 529。画像（P18）508、Commons カテゴリ 368、創建年（P571）266、宗派（P140）269、開基（P112）153、文化財指定（P1435）108。
- 京都市内の P1435 の内訳: 重要文化財 190、国宝 134、史跡 41、登録有形文化財 28、名勝 26、世界遺産構成資産 17、特別名勝 14。
- 現データとの名寄せ: 519 施設・事物のうち、寺社城クラス限定の 529 件とラベル完全一致で **90 件**（画像 82、創建年 63、指定 46）。名木・地名・料理などは別クラスのため未照合。寺社に限れば実用的、全体の「写真問題」の母集団にするにはクラス拡張と手作業の名寄せが必要。
- 画像本体は Wikimedia Commons。ライセンスはファイルごと（CC BY-SA 等）で、表示時に作者・ライセンス表記が必要。games.hidetaka.dev の CSP では `img-src` に `upload.wikimedia.org` を足せる（京都地下鉄クイズで実績あり）。

### 2.3 総務省統計局 家計調査 都市別ランキング
- URL: https://www.stat.go.jp/data/kakei/5.html （「ランキング（2023年（令和5年）～2025年（令和7年）平均）」、`zuhyou/rank01.xlsx`〜`rank14.xlsx`: 穀類・魚介類・肉類・乳卵類・生鮮野菜・乾物等・果物・油脂調味料・菓子類・調理食品・飲料・酒類・外食・食料以外）
- 粗解析（openpyxl、結合セルのため品目名と金額/数量の対応は要再検証）で京都市が **1 位**: ヨーグルト、バター、牛肉（および肉類・生鮮肉の合計）、コーヒー、はくさい、きゅうり、さといも、はくさい漬、他の大豆製品、外食の和食。2 位: 豆腐、納豆、なす、ピーマン、プリン、電気代、コーヒー・ココア 等。3 位: パン（金額）、米、柿、こんぶ、緑茶 等。
- 用途: 「京都市が全国 1 位なのはどれ？」「京都市のパンの順位は？」。数値データは著作権の対象外とされ、利用規約上も商用可・出典記載（例:「家計調査結果」（総務省統計局）を加工して作成）。
- 注意: 2 人以上の世帯・3 年平均という条件を問題文か解説に明示する。

### 2.4 e-Stat（API）
- 利用規約（https://www.e-stat.go.jp/terms-of-use）原文: 「複製、公衆送信、翻訳・変形等の翻案等、自由に利用できます。商用利用も可能です」「数値データ、簡単な表・グラフ等は著作権の対象ではありません」「政府標準利用規約（第2.0版）に準拠」「CC BY と互換性があり」。加工した場合は「『○○調査結果』（A省）を加工して作成」等と記載。
- API（https://www.e-stat.go.jp/api/）は **ユーザ登録（appId）が必要**。ビルド時取得に使う場合は appId を CI シークレットに置く。ランキング xlsx のように登録不要のファイルで足りる範囲は API 不要。
- 候補統計: 地域特産野菜生産状況調査（令和6年産、2026-06-30 公表、都道府県別の作付面積・収穫量・出荷量 表あり）、経済構造実態調査（製造業、品目別）。後者は都道府県×細品目の表が現行で公開されているか未確認。

## 3. ゲームファミリー側の制約（games.hidetaka.dev）
- `cdk/src/apps.ts` に 1 要素追加すれば `https://games.hidetaka.dev/<slug>/` で配信される。GitHub Pages オリジンの実例が `anthropic-version-quiz`（Angular 22、`style-src 'unsafe-inline'` のみ緩和、`inlineCritical: false`）。
- CSP は `script-src 'self'` 固定。外部スクリプト・インラインスクリプト・外部計測タグは使えない。画像は `img-src` の allowlist 追加で Wikimedia・地理院タイル等を許可できる。
- 既存の「京都地下鉄マニアッククイズ」（市営地下鉄 32 駅）と題材が重ならないよう、地下鉄駅情報は使わない。
